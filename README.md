# Программный модуль подсказок тематик обращений граждан

Репозиторий содержит программную реализацию магистерской диссертации на тему:

> Разработка программного модуля тематической маршрутизации текстовых обращений граждан на основе методов обработки естественного языка и машинного обучения

Модуль предназначен для формирования ранжированного списка тематик из фиксированного справочника по тексту обращения гражданина. В пользовательском сценарии модуль не назначает тему автоматически, а возвращает список наиболее релевантных вариантов `Top-10`, из которого пользователь или внешняя логика интерфейса может выбрать итоговую тематику.

Задача решается как closed-set ранжирование: модель возвращает только темы из заранее заданного справочника и не генерирует новые тематики.

---

## Назначение проекта

Проект реализует сервис подсказок тематик обращений граждан.

Основные функции:

- приём текста обращения через HTTP API;
- формирование `Top-10` тематик из фиксированного справочника;
- возврат скорингов, рангов и диагностической оценки уверенности;
- проверка согласованности предсказаний с обучающим контрактом модели и справочником;
- логирование инференса в структурированном формате;
- приём пользовательской обратной связи;
- формирование основы для последующего анализа ошибок и active learning.

Модуль не выполняет дальнейшую бизнес-маршрутизацию обращения по исполнителям, регламентам или статусам. Эта логика находится вне границ данной реализации.

---

## Итоговая модель

В качестве итогового решения используется гибридная модель `three_way_hybrid`, объединяющая три источника сигнала:

1. `TF-IDF + LinearSVC` — лексический sparse-классификатор;
2. `multilingual-E5 + FAISS` — dense retrieval по центроидам тематик;
3. `BM25` — лексический retrieval по агрегированным текстам тематик.

Итоговое ранжирование строится через late fusion:

- от каждого канала берутся кандидаты;
- скоринги нормализуются по текущему запросу;
- итоговый score вычисляется как взвешенная сумма;
- первые 10 тематик формируют ответ сервиса.
